# 작업 전환 안내 규칙

2026-10-28 사용자 요청: 다음 Task로 넘어갈 수 있는지와 그 시점을 앞으로도 안내한다.

각 Task의 종료·중단 시 목표 대비 결과, 실제 검증 증거, 남은 문제와 해결 경로,
다음 Task의 제안 범위 및 진입 가능 여부를 간단히 알린다.
Task별 완료와 전체 연구 완료를 구분한다. 코드를 작성한 것만으로 실행·검증 완료로
판정하지 않는다. 기존 사용자 결정은 재확인 없이 유지한다.

| 진입 판정 | 기준 |
| --- | --- |
| 가능 | 다음 작업에 필요한 범위·선행 근거가 갖춰져 해당 작업을 시작할 수 있음 |
| 조건부 | 독립 작업은 시작할 수 있으나 특정 단계 전에 추가 근거·결정이 필요함을 명시 |
| 보류 | 다음 작업의 필수 근거·연구 정의가 없어 진행할 수 없음. 해결 경로와 2~3개 선택지를 제시 |

다음 작업에서 검증할 미확인 사실 자체가 있다는 이유만으로 진입을 막지 않는다.
예를 들어 가용성 조사 단계는 확보 가능성을 아직 모르는 상태에서 시작할 수 있다.
조사가 불가 결론으로 끝났다면 조사 완료와 후속 모델 작업 진입 불가를 구분한다.
연구 정의가 모호하면 기존 지침대로 임의 가정하지 않고 중단·질문한다.
상태·증거·후속 행동은 work_progress.json에 기존 이력을 보존해 기록한다.
단계 전환 안내는 자동 일정·백그라운드 모니터링이 아니라 해당 작업 대화의 종료 보고다.

## 현재 전환 판정

Task 01 감사·범위 정리는 완료했으므로 Task 02 진입은 가능하다.
Task 02의 제안 우선 범위는 시장가치 소표본 가용성 검증이다.
기존 연구 범위·최초 공개본·T 직전 거래일 가격 원칙을 따르고,
정상·폐지·거래정지 및 주식종류별로 당시 자료의 접근·필드·누락·시점 근거를 확인한다.
이 검증은 ①C 선택에 따른 최종 Altman 변형 결정의 선행 작업이다.
과거 업종·최초 공시본의 증거 확보 경로도 후속 데이터 준비에 필요한 의존성으로 기록한다.
샘플 크기·선정 기준 등 구체 실행 범위는 시작 시 명시하며, 이 문서 작성에서
소표본 수집·분류·모델 학습은 실행하지 않았다.

Task 02 종료 때는 접근 성공 여부, 필요한 시점·필드의 실제 증거, 실패·누락 범위와
해결 경로를 제시하고 원형 Z와 Z′의 최종 선택 필요 여부를 알린다.
그 결과 없이 원형을 확정하거나 대량 수집·모델 비교 단계로 자동 전환하지 않는다.
Task 03 이후 번호별 범위는 아직 확정하지 않았으며 각 전환 시 제안한다.
