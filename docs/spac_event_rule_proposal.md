# 24건 SPAC 폐지사유 검토 및 규칙 수정안

상태: 공식 근거 검토 완료. Task03 전체 미완료. 판정규칙 수정안은 미적용. 사용자 B의 검토 후 수집 재개 순서를 따른다.

## 확인 결과

24건 모두 KRX 공식 사유가 합병 예비심사 서류 미제출 후 관리종목 사유 미해소였다. 실제 합병이 완료된 사건으로 확인한 것이 아니다. 24개 회사의 연구기간 사업보고서 최초제목후보64건을 각 공개일T와 상장기간에 대조하고, 접수번호 원문 해시/CRC와 회사 자신의 유일한 사업목적 문단을 확인했다. 검토한64개T에서 주된 사업은 SPAC 합병 준비 활동이며 기존 제조업 범위 밖으로 판정한다. 판단은 검토한T에 적용하며, 이후 다른 사업을 영위하는 시점은 당시 자료로 다시 판정한다.

합병 대상 후보 산업 목록이나 폐지 당시 금융업 표기를 과거 판정에 소급하지 않았다. 접수번호별 본문과 공개일·문서명·XPath·해시를 보존했다. 최초 재무수치 자체의 검증 완료는 의미하지 않는다.

- T별 업종 사실검토: data\interim\industry_review_spac_20261028_215543_916757.csv

- 공식 공개 예시: [상상인제3호 2022 사업보고서](https://kind.krx.co.kr/external/2023/03/20/000406/20230320002187/11011.htm). 다른 회사와의 합병을 사업목적으로 기재한 본문은 2023-03-20 공개 자료다.

## 구체적 수정안

1. 기업·T별 업종 적격성을 먼저 확인한다. 이번64개T는 주된 사업이 SPAC이므로 제조업 표본 제외 사유를 기록한다. 정상 라벨0이나 실제합병 경쟁사건으로 바꾸지 않는다.
2. 합병 예비심사 신청서/청구서 미제출·존립기한 등 실패 문맥을 별도 검토 항목으로 분리한다. 합병 문자열만으로 경쟁사건 확정값을 반환하지 않는다. 해당 사유가 제조업 적격 관측치에 연결되는 새 사례는 공식 근거를 검토할 때까지 NA로 보존한다.
3. 실제 합병·이전상장 등 경쟁사건은 공식 사건유형 확인 후 판정한다. 이 수정안은 SPAC 실패를 제조업 부실양성으로 일괄 편입하는 규칙을 새로 만들지 않는다.
4. 적용 검증에서는 이번24문구의 경쟁사건 자동확정 방지, 실제 합병 경쟁사건 유지, T별 업종0과 라벨0의 구분, 제조업 합병대상 후보와 SPAC법인 구분을 확인해야 한다.

현재 src/labeling.py는 변경하지 않았다. 원자료 수집은 판정규칙을 모델 라벨로 확정하지 않고 재개할 수 있다. 후속 실제 라벨 생성 전에 이 수정안을 적용·검증해야 한다. Task04는 실행하지 않는다.
