# 프로젝트 현황

기준일: 2026-08-01

## 1. 프로젝트 목표

KOSDAQ 제조업 상장기업의 재무제표를 이용해 관측시점 `T` 이후 12개월
이내 부실성 상장폐지 여부(`상장폐지_t12`)를 예측한다. Altman Z-Score를
기준모형으로 삼고 Logistic Regression, Random Forest, XGBoost와 성능을
비교한다.

최종 연구 질문은 다음과 같다.

> 재무제표 기반 머신러닝 모델은 기존 Altman Z-Score보다 상장폐지 예측
> 성능이 우수한가?

## 2. 연구 범위와 원칙

- 표본 사업연도: 2015~2024
- 대상 시장과 업종: KOSDAQ 제조업 보통주 기업
- 관측시점 `T`: 사업보고서가 실제 공개된 DART 공시 접수일
- 예측기간: `T` 이후 12개월
- 재무제표: 연결재무제표 우선, 미제공 시 별도재무제표 사용
- 양성 사건: 재무적·규제적 사유의 상장폐지
- 제외 사건: 합병, 이전상장, 자진상장폐지, SPAC 합병 등의 경쟁사건
- 불확실한 폐지사유와 관측기간이 부족한 표본은 임의 분류하지 않고 결측 처리
- 전처리와 통계량 계산은 학습 데이터에서만 수행하여 데이터 누수를 방지

## 5. 현재 중단 사유

KIND 현재 상장기업과 KRX 과거 상장폐지기업의 업종 분류 체계가 다르다.
현재 자료는 업종명에 `제조업`이 직접 표시되지만 과거 자료는 반도체,
기계·장비, 화학 등의 세부 업종으로 표시되거나 업종이 비어 있다.

기존 필터를 그대로 사용하면 과거 상장폐지 제조업 기업이 빠져 양성 표본이
사라질 수 있다. 이 상태에서 수집과 모델링을 계속하지 않고 체크포인트를
보존한 채 중단하였다.

검토 중인 기준은 DART 기업개황의 5자리 업종코드 앞 두 자리가 `10~34`인
기업을 제조업으로 판정하고, KRX 자료에서는 `주권`만 사용하는 방식이다.
다만 해당 업종코드가 각 과거 관측시점이 아닌 기업의 최종·최근 정보일 수
있다는 한계를 문서에 남겨야 한다.
