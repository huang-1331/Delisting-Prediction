# Methodology

## 연구 질문

재무제표 기반 머신러닝 모델은 기존 Altman Z-Score보다 상장폐지 예측 성능이 우수한가?

## 예측 단위

- 관측 단위: 기업-시점
- 표본 사업연도: 2015~2024
- 사용 보고서: 사업보고서
- 입력 시점 `T`: 해당 재무제표의 DART 공시 접수일
- 재무제표 범위: 연결재무제표 우선, 연결이 없을 때 별도재무제표 사용
- 예측 대상: `T+12개월` 이내 상장폐지 여부
- 타겟 변수: `상장폐지_t12`

## 기업 모집단

- KRX/KIND 공식 자료를 결합해 현재 상장기업과 과거 상장폐지기업을 모두 포함한다.
- 현재 상장기업은 시장구분이 KOSDAQ이고 KIND 업종명에 `제조업`이 포함된
  보통주 기업을 사용한다.
- TODO: 과거 상장폐지기업은 KRX 주권만 사용하고 DART 업종코드로 제조업을
  판정하는 방안의 시점 적합성을 확정한다.
- 각 기업-시점은 상장일 이상, 상장폐지일 미만인 기간에만 관측치로 인정한다.
- KRX 종목코드와 DART 종목코드를 우선 결합한다.
- 종목코드가 없는 과거 기업은 정규화된 회사명이 DART 기업 하나와 정확히
  일치할 때만 보조 결합한다. 퍼지 매칭과 복수 후보는 사용하지 않고 수동 검토한다.

## 상장폐지 라벨

- KRX Data Marketplace 화면 20037의 폐지일과 폐지사유를 공식 사건 정보로 사용한다.
- 감사의견, 자본잠식, 부도, 파산, 보고서 미제출, 공시의무 위반,
  상장적격성 문제 등 재무적·규제적 상장폐지를 양성 사건으로 정의한다.
- 합병, 주식교환·이전, 이전상장, 자진상장폐지, SPAC 합병은 경쟁사건으로
  처리하고 해당 관측치의 라벨을 결측 처리한다.
- 사유 문구가 규칙에 포함되지 않으면 임의 분류하지 않고 `NA`와 수동 검토
  목록으로 남긴다.
- 사건일은 `T`보다 커야 하며 `T+12개월` 이하일 때 양성으로 처리한다.
- 라벨 관측 기준일보다 `T+12개월`이 늦으면 우측 검열로 `NA` 처리한다.

## 데이터 누수 방지

모델 입력 변수는 `T` 시점에 관측 가능한 재무제표 정보로 제한한다.

- DART `rcept_no`로 공시목록의 접수일을 결합하며 접수일을 확인할 수 없는
  재무제표 행은 모델 데이터에 포함하지 않는다.
- 상장폐지일, 상장폐지 사유, 사유 분류 결과는 라벨 생성에만 사용하고
  모델 입력 데이터에는 복사하지 않는다.
- OpenDART 정정 공시로 값이 변경될 수 있으므로 접수번호, 수집시각,
  연결·별도 구분을 원자료에 보존한다.
