# Methodology

## 연구 질문

재무제표 기반 머신러닝 모델은 기존 Altman Z-Score보다 상장폐지 예측 성능이 우수한가?

## 예측 단위

- 관측 단위: 기업-시점
- 입력 시점: `T`
- 예측 대상: `T+12개월` 이내 상장폐지 여부
- 타겟 변수: `상장폐지_t12`

## 데이터 누수 방지
