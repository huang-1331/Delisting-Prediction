# 12개월 완전자본잠식 데이터로 MLP 재학습

첨부 모델의 은닉층 구조 3가지와 양성 가중치 적용 여부를 조합해 6가지 후보를 만들었다. 첨부 모델의 학습 가중치나 경고선은 사용하지 않았다. 입력은 기존 완전자본잠식 실험의 기업·분기 재무비율과 추세이며 영업이익으로 EBIT을 대체할 필요가 없다. 양성 가중치 후보는 적합 폴드의 역빈도를 최대 15배로 제한했다. 후보마다 난수 시드 42·43·44로 학습한 세 모델의 평균을 사용했다.

학습 기업을 기준으로 층화 3분할 교차검증을 3회 반복했다. 결측 중앙값과 표준화는 각각의 적합 폴드에서 계산했다. 후보별 경고선은 교차검증 재현율 80% 이상인 점에서 정밀도를 최대화하도록 고정했다. 최종 후보도 같은 개발 기준으로 선정했다. 이후 전체 학습셋으로 다시 적합하고 고정 경고선으로 테스트했다. 교차검증과 전체 재적합 간 점수 분포 차이로 테스트에서 같은 재현율이 보장되지는 않는다.

평가는 기존 순손실 및 좁은 순손실 1차와 부스팅 2차의 비교에 사용한 동일한 기업·분기 행에서 수행했다. 학습 및 평가 기업 중복은 0곳이다. 반복 사용한 기존 테스트의 후향 평가다.

## 실행

```bash
python -m pip install -r requirements.txt
python run.py fit train_snapshots.csv.gz source_financial_history.csv.gz public_known_registry.csv results
python run.py test test_snapshots.csv.gz source_financial_history.csv.gz public_known_registry.csv results --prior prior_projection_predictions.csv.gz --boosting prior_rescue_test_12.csv.gz
```

`results/lock.json`에는 학습셋 교차검증 지표와 고정 경고선, `results/models.joblib`에는 fit 실행에서 생성되는 재학습 모델, `results/test.csv`와 `results/predictions.csv.gz`에는 집계와 행별 결과가 기록된다. 이 저장소에는 경고선과 집계표를 포함했다. 신뢰할 수 있는 모델 묶음만 불러온다.

## 결과

순손실 기준의 계산, 고정 경고선과 실행 방법은 [순손실 알고리즘](../순손실%20알고리즘/)에서 확인할 수 있다.

학습 1,581행(64기업, 부실 20행·6기업), 평가 1,377행(59기업, 부실 74행). 개발에서 선정된 MLP 32–16–8은 평가에서 적중 31건, 오경보 287건, 재현율 41.89%, 정밀도 9.75%였다. MLP 6종 중 최고 재현율은 54.05%로, 재현율 80% 달성 후보는 없었다. 순손실 기준은 재현율 82.43%, 정밀도 14.73%였다.

| 모델 | 재현율 | 정밀도 | 적중 | 오경보 | 누락 |
|---|---:|---:|---:|---:|---:|
| MLP_16_8 | 40.54% | 8.90% | 30 | 307 | 44 |
| MLP_16_8_weighted | 35.14% | 9.15% | 26 | 258 | 48 |
| MLP_32_16_8 | 41.89% | 9.75% | 31 | 287 | 43 |
| MLP_32_16_8_weighted | 50.00% | 6.27% | 37 | 553 | 37 |
| MLP_32_32_16_8 | 54.05% | 6.27% | 40 | 598 | 34 |
| MLP_32_32_16_8_weighted | 47.30% | 6.18% | 35 | 531 | 39 |
| 순손실 | 82.43% | 14.73% | 61 | 353 | 13 |
| 순손실+부스팅 | 78.38% | 17.26% | 58 | 278 | 16 |

`--prior`에는 순손실 폴더의 `refine.py test`가 생성한 `predictions.csv.gz`를 전달한다. `--boosting`에는 기존 12개월 순손실 + 부스팅 실험의 행별 결과를 전달한다. 비교 시 기업 코드, 예측 기준일, 라벨이 일치해야 한다.
